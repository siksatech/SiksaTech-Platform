# SiksaTech UI/UX Design System Rule

All frontend code across `siksatech.in` and `team.siksatech.in` MUST adhere to the following 3-color palette and mobile-first standards:

1. **Max 3 Primary Colors**:
   - **Obsidian Navy (`#0A0F1D` / `#0F172A`)**: Primary base, dark backdrops, deep text.
   - **Electric Blue (`#2563EB` / `#38BDF8`)**: Primary action, circuit accents, badges, highlights.
   - **Clean White/Slate (`#FFFFFF` / `#F8FAFC`)**: Pedagogical reading canvas, card backgrounds.
2. **Design Ideology**: "Maker-Tech Neo-Clean" (1px crisp borders, tactile cards, monospace badges, breadboard grids).
3. **Mobile-First Layouts**: Ensure &ge;44px touch targets, sliding mobile drawer navigation, responsive banner aspect ratios (`21:7` desktop / `16:9` mobile), and seamless single-column mobile stacking (`grid-cols-1`).
